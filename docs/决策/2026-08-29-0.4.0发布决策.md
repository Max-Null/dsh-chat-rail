# dsh-chat-rail 0.4.0 发布决策（2026-08-29）

## 版本决定

- **0.3.1 → 0.4.0**（minor）：新增收藏/快速填充功能 + 多个 UI 修复，非 break，按 semver 升 minor。
- 依据：功能新增（收藏星/加号/黄色导航条/过滤开关/tooltip）+ 大量样式打磨。

## 发布分工（既定惯例）

- 代理（本会话）：版本 bump、构建产物、GitHub 提交/tag v0.4.0 对齐、给 npm publish 指令。
- 用户：npm login 后手动 `npm publish`（npm 已开 2FA，代理 E401 无法代发）。
- 发布后：代理更新 profile 声明（ssid/web 的 `^0.3.1` → `^0.4.0`）+ pnpm install + SSiD prepare-runtime 归档同步提醒。
