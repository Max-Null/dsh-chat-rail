## 一、TypeError：`this` 绑定（9/6，已修复）

- **现象**：会话导航条点击 → `TypeError: Cannot read properties of undefined (reading 'openState')`
  （`session.ts:391` → `index.tsx:922` → `index.tsx:1478`，栈逐行吻合）。
- **根因**：`src/client/index.tsx` `jumpToMessage()` 把类方法解构后裸调
  （`const jumpLoadThrough = session.loadThrough; jumpLoadThrough(seq)`）→ `this === undefined`。
- **修复**：方法调用 `jumpSession.loadThrough(targetSeq)`；新增回归测试
  （`tests/client-nodes.spec.ts`「invokes loadThrough as a method...」——修前红、修后绿）。
- **验证**：web(3080) L2 点击 0 error；SSiD dev L2 同路径 0 error（修复前旧实体 0.5.0 同路径
  报错 ×4 的实测基线）。

## 二、跳转四件套（9/7，已修复）—— 用户大会话实测暴露

| # | 症状 | 根因（插件侧） | 修复 | 官方参照 |
|---|---|---|---|---|
| 1 | 点任意导航点都「先加载再跳转」（近距目标亦然） | `jumpToMessage` 无条件 `loadThrough(targetSeq)`，无「已加载」判断 | 新增 `isLoaded(key)` 快路径：已加载直接滚动，不翻页 | 官方 `TurnNavigator`（`ui-chat/ChatView.tsx` `navigateToTurn`）：`anchor.kind==='loaded'` 直接 `anchorElement`+滚动，仅 `unloaded` 走 `loadThrough` |
| 2 | **首条点击无效**（跳转不到首个消息） | `scrollToRow` 中 `if (target < 0) return`——首条行位于文档头部，居中公式的目标恒为负 → 直接放弃滚动 | `Math.max(0, …)` clamp 到顶（默认仍居中，仅钳制负值） | 用户初始推测「DSH 改了首条格式」——实测**不成立**：`13:input-message<uuid>` 键仍存在（DOM 138 个 anchor key 中 2 个 input-message；key 规则 `\`${kind.length}:${kind}${id}\``，见 `ui-conversation/contract/conversation.ts` `conversationContextKey`） |
| 3 | 滚到目标后仍显示「加载中」 | `jumping` 状态覆盖 `jumpToMessage` **全程**（含滚动后 4×600ms 稳定性验证 ≈2-4s），与滚动完成不同步 | 新增**阶段信号** `onJump('paging' \| 'landed')`：`'paging'`（真正翻页）才显示 busy；`'landed'`（行已定位、将滚动）立即清除；近距目标全程无 busy | 官方模式：加载指示只表征「异步分页进行中」，滚动是即时视觉反馈 |
| 4 | 「加载中」出现引出滚动条，时有时无 | `.crl_loading` 粘性行出现/消失 → rail 展开态容器高度波动 → 细滚动条闪现 | 隐藏 rail 滚动条（`scrollbar-width:none` + WebKit `width:0`；`overflow-y:auto` 保留 → 仍可滚轮滚动） | 用户建议采纳 |

## 四、归属结论（是否 DSH 升级导致的 bug？）

**不是**——三项均为插件自身缺陷，rc.1 的 `loadThrough` 跳转 API + 异步窗口装配
「放大」了它们（详见决策记录 2026-09-06 文件「9/7 复核 + 归属」节）：

- 症状 1/3：适配新 API 时未按官方 loaded/unloaded 模型建模（插件责任）；
- 症状 2/4：插件滚动计算缺 clamp 兜底 / busy 状态生命周期过宽 / CSS 滚动条布局
  （与升级无关，仅测试覆盖盲区——上轮 L2 只验「不报 TypeError」，未验「滚到位」）。
- 结论表：

| 症状 | 引入方 | 与升级关系 |
|---|---|---|
| 先加载 | 插件：无 loaded/unloaded 二分 | 相关（适配瑕疵，非官方行为变化） |
| 首条无效 | 插件：`target<0 return` | 无关（长会话必现；升级前未被测到） |
| 加载中残留 | 插件：busy 状态覆盖全程 | 相关且放大（新 API 异步装配更长） |
| 滚动条闪现 | 插件：CSS/粘性行布局 | 无关 |
