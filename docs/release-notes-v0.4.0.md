# dsh-chat-rail 0.4.0

画卷式消息导航，新增**收藏与快速填充**。

## ✨ 新功能

- **消息操作按钮**：每条用户消息的复制按钮左侧新增两个按钮
  - **星 ★**：收藏/取消收藏（收藏后变为黄色实心星），按会话持久化
  - **加号 ＋**：一键把消息全文 + 历史附件回填输入框（走官方附件通道）
- **导航条联动**：收藏的消息指示条显示为黄色；展开态标题前显示黄色星标
- **只显示收藏**：导航条顶部星形过滤开关，点亮后只显示收藏的消息

## 💾 持久化（host 侧）

- 收藏数据存 **host 文件**（`~/.dsh/chat-rail-favorites.json`，经 `/chat-rail/api/favorites` GET/PUT）
- 为什么：client `localStorage` 按 origin 隔离，思灵 DSH web 端口每次启动随机 → 旧方案跨重启丢收藏
- localStorage 旧数据自动一次性迁移后清除；加载完成前以 localStorage 兜底

## 🎨 UI 打磨

- 星/加号按钮与复制按钮完全同款：28px 圆形、DSW token 颜色、hover 浅蓝圆背景
- hover 黑底 tooltip（收藏消息 / 取消收藏 / 填充到输入框），与 host Tooltip 一致
- 展开态筛选按钮为完整标签行（星 + 「只显示收藏」），杜绝竖排
- 收藏条为当前阅读位置时光晕同色（黄），不再「黄点蓝光」
- **筛选按钮钉在导航条顶部**（sticky，长会话滚动不跟随滚走）
- **无收藏时隐藏筛选按钮**（过滤激活时取消最后一条收藏自动释放过滤）

## 🐛 修复

- `conversation` 服务注入声明（此前直接访问导致插件崩溃）
- 只显示收藏过滤下剩 1 条时导航条不再消失
- host 半端 `webServer` 注入导致投影单测批量失败（fake 服务分流修复）
