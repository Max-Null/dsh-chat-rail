# dsh-chat-rail 0.4.0

画卷式消息导航，新增**收藏与快速填充**。

## ✨ 新功能

- **消息操作按钮**：每条用户消息的复制按钮左侧新增两个按钮
  - **星 ★**：收藏/取消收藏（收藏后变为黄色实心星），按会话持久化（localStorage），刷新与重启保留
  - **加号 ＋**：一键把消息全文 + 历史附件回填输入框（走官方附件通道）
- **导航条联动**：收藏的消息指示条显示为黄色；展开态标题前显示黄色星标
- **只显示收藏**：导航条顶部星形过滤开关，点亮后只显示收藏的消息

## 🎨 UI 打磨

- 星/加号按钮与复制按钮完全同款：28px 圆形、DSW token 颜色、hover 浅蓝圆背景
- hover 黑底 tooltip（收藏消息 / 取消收藏 / 填充到输入框），与 host Tooltip 一致
- 展开态筛选按钮为完整标签行（星 + 「只显示收藏」），杜绝竖排
- 收藏条为当前阅读位置时光晕同色（黄），不再「黄点蓝光」

## 🐛 修复

- 会话作用域声明 `conversation` 服务注入（此前直接访问导致插件崩溃）
- 只显示收藏过滤下剩 1 条时导航条不再消失
