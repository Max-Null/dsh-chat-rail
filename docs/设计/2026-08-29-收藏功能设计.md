# dsh-chat-rail 收藏功能（2026-08-29）

> 需求（用户口述 + 截图）：消息气泡复制按钮左侧加两个按钮——星（收藏，点亮变黄）+ 加号（快速填充到输入框，带附件）。收藏后导航栏对应导航条黄色显示 + 导航条上方星星图标，点亮后导航栏只显示收藏的导航条。

## 调研结论（读 DSH 0.1.1-rc.2 源码实证）

### 官方扩展点
- `conversation.chat.assistant-actions`（list/session）：只渲染在**助手**消息的 IconActions 行（TurnTailNodeView → extraActions）。**用户消息无槽**（UserMessageNodeView 不传 extraActions）→ 收藏按钮必须 DOM 注入：`[data-chat-anchor-key^="13:input-message"]` 行内找 aria-label 含「复制/Copy」的按钮，插其左侧。
- `conversation.input.dock`（本插件已占）：会话作用域组件自动获得 `useInput` + `inputActions`（SessionStandardProps 注入）。
  - `inputActions.setDraft(text)`：公开单写路径（跨包可用，InputActions 面）。
  - `inputActions.addImages(ids)`：需要 `DraftAttachmentId`（browser-owned id，由 `createDraftImages(files)` 生成）。
- `ctx.conversation`（IConversation 服务）：`createDraftImages(files: File[])` → `ComposerAttachment[]`（含 id）；`readAttachment` 在 session 面（`session.readAttachment(attachmentId)` → `{attachment, data: Uint8Array}`）。
- **填充链路（带附件）**：读历史附件 bytes → `new File([data], name, {type: mediaType})` → `conversation.createDraftImages([file])` → `attachment.id` → `inputActions.addImages([id])` + `inputActions.setDraft(text)`。

### 收藏存储
- localStorage，key = `@max-null/dsh-chat-rail:favorites`，值 = `{ [sessionId]: string[] }`（消息 durable id 数组，来自投影 `id`）。跨会话隔离、刷新保留。
- 状态同步：DOM 按钮（收藏/填充）与 React 导航条共享一个模块级 store（`FavoritesStore`，useSyncExternalStore 订阅），收藏变更即时点亮导航条。

### 导航栏（rail）交互
- 收藏的导航条：`.crl_line` 黄色 + `crl_show` 态显示星标图标。
- rail 顶部（折叠态也可见？否——折叠态 36px 胶囊只有指示条）→「导航条上方星星图标」= 展开态容器顶部一个星形开关按钮；点亮（或常显）后只显示收藏导航条（过滤模式）。折叠态仅指示条黄色不变。
- 需求原文「在导航条上方增加星星图标，点亮后，导航栏只显示收藏的导航条」→ 实现为 rail 顶部星形切换按钮，激活时列表过滤为收藏项。

## 技术风险
- DOM 注入依赖 aria-label 文案（zh「复制」/ en「Copy」），DSH 更新 locale 需同步跟进（同 data-slot 锚点评测，注释注明）。
- `inputActions` 仅会话作用域槽可用；rail 已在 dock 槽内，可直接用。
- 附件填充：`readAttachment` 是 RpcResult 包装；文件命名 `attachment-<id>.<ext>`（ext 从 mediaType 推断，未知回退 .bin——DSH 会按 MIME 校验接收）。
- 纯 client 改动，无 host 侧变更；投影 id（durable）已有（v0.3.1 起的 `id` 字段），无需改投影。

## 社区参考调研（已克隆源码验证，2026-08-29）

- **dsh-milestone**（SnowCrescenter-tech）：收藏实现范本
  - `bookmarkStore.ts`：defineStore + localStorage 持久化（`dsh-milestone.bookmarks`），per-session `create(scopeKey)`；纯 toggleKey 逻辑。
  - `MilestoneRailTooltip.tsx`：星形按钮 = `#ffd166` 填充（收藏态）/ `#8b96ab` 空心（未收藏），`aria-pressed` + `data-starred`；SVG path `m12 2 3.09 6.26L22 9.27l-5 4.87 1.18 6.88L12 17.77l-6.18 3.25L7 14.14 2 9.27l6.91-1.01L12 2z`。
  - rail 顶部 `bookmarksOnly` 过滤按钮（`aria-pressed` + ChromeButtonStyle 点亮），`filterByBookmarks(...)` 只留收藏项——与需求「导航栏只显示收藏的导航条」完全对应。
  - DOM 锚点确认：`[data-chat-anchor-key]` 含 `data-chat-flow-kind`，消息行外层 flowItem；用户行 key 前缀 `13:input-message`。
- **dsh-client-ui-quote**（skyhancloud）：填充范本
  - 注册于 `conversation.input.dock`（同本插件），组件直接收 `input`/`inputActions`（framework 注入 SessionStandardProps）。
  - 引用路径：`inputActions.setQuote(...)`（feature-detect，rc 线可能没有）→ 降级 `inputActions.setDraft(mergeDraft(...))`。
  - 填充后 `textarea.focus({preventScroll}) + setSelectionRange` 聚焦输入框——加号填充沿用。
  - 纯 client，无 host 半端改动。
- **重要差异**：两份参考都只做「复制/引用/书签展示」，**没有历史附件回填输入框的先例**。附件填充链路（readAttachment → File → createDraftImages → addImages）需自研，`IConversation` 类型面未暴露 `createDraftImages`（ConversationController 运行时方法），须 cast 局部接口，运行时装不上对话服务时降级为仅文本填充。
